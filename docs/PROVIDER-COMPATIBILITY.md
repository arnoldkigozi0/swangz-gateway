## 4. Claude Code and Codex (kind `dev`) — the sharpest legal edge

DOC-V (Probe read it): Claude Code legal page, https://code.claude.com/docs/en/legal-and-compliance, 2026-11-02:
- API-key authentication is the route for developers building products; Anthropic "does not permit third-party
  developers to offer Claude.ai login into their own applications, or to route requests through Free, Pro, Max, or
  Ultra plan credentials on behalf of their users", and developers "may not collect, store, or intermediate Claude.ai
  credentials or session tokens".
- That "does not restrict how customers provision and manage their own API keys … for use by the customer's own
  authorized users — provided the resulting usage is billed to the key owner".
- Separately, products that run Claude Code "may not pay for, resell, or intermediate Claude usage on their end users'
  behalf".

Reading (INFERENCE): pointing staff Claude Code at the gateway on a **company API key** is the documented-safe shape
(model A). Using staff subscription tokens through the gateway is not permitted (model C/D must not be proxied).
Whether an internal gateway that fronts a company key counts as "intermediating" under the last bullet is **not
settled by the page**; it is written for products offered to end users. Recommendation: get a one-line written
confirmation from Anthropic sales before relying on it in a policy. Codex: OpenAI documents ChatGPT-plan sign-in **or**
API key, API key billed separately (DOC-R, [auth](https://learn.chatgpt.com/docs/auth)); same rule applies — API key
through the gateway, never plan tokens.

### 5.1 Catalogue defects found (REPO + DOC-R)

- **Sora** (`sora`): OpenAI states the Sora web/app closed 2026-04-26 and the API on 2026-09-24
  ([notice](https://help.openai.com/en/articles/20001152-what-to-know-about-the-sora-discontinuation), DOC-R; Probe's own
  fetch returned HTTP 403, so re-confirm in a browser). The catalogue still lists `sora` with host `sora.com`, and the
  `chatgpt` tool also owns `sora.com`. Recommendation: archive `sora`, drop the host.
- **DALL-E** (`dall-e`): OpenAI deprecation page says DALL-E 2/3 API models shut down 2026-05-12
  ([page](https://developers.openai.com/api/docs/deprecations#2025-11-14-dall-e-model-snapshots), DOC-R). Entry points at
  `openai.com`. Recommendation: review/archive.
- **Host collision**: `seedance` and `higgsfield-ai` both declare host `higgsfield.ai`; `chatgpt` and `sora` both claim
  `sora.com`. The access gate (`host_index`, longest host wins) cannot tell these tools apart, so entitlement and
  attribution of those visits are ambiguous. Not reproduced by test yet — **UNVERIFIED**, listed for Forge.
- Catalogue `entry_usd` and plan prices were not re-verified (not part of this task).
